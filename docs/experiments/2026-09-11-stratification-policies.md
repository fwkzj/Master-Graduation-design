# S 线：分层边界策略的完整实验记录

日期：2026-09-11 ・ 数据源：`runs/strat2_p0..p5`（调试集）、`runs/full23w_strat_p0/p2`（全量，种子 20260909）、
`runs/seed2_strat_p0/p2`（全量，种子 20260910）・ 提交 `38bf80f`、`ae4d4c4`、`dfd4b0e`

## 1. 实现了什么

`--strat=N` 强制切换 CASH 内部的分层边界策略，并在每个决策点通过 `STRAT_DEBUG` 输出边界值：

| N | 策略 | 边界取法 |
|---|---|---|
| 0 | P0 几何对折（历史规则） | `W - max(1, W/2)` |
| 1 | P1 质量均衡 | 使本层承载约一半的剩余权重质量 |
| 2 | P2 硬化对齐 | 取不大于 `UB − LB` 的最大权重 |
| 3 | P3 间隙驱动 | 最大相对权重间隙处（且间隙大于其下全部权重之和） |
| 4 | P4 代价模型 | 假设数预算内最大化单位假设的权重质量 |
| 5 | S2 在线自适应 | 在 P0 与 P2 之间按上一层换回的 LB 进展在线切换 |

关键修复：策略最初只作用于「再次分层」的路径，而难实例在第一个层级里就要耗掉大半预算
（`causal_Link`：90 秒内 0 次分层决策，300 秒内 11 次），所以**第一个层级也必须走策略**。
补上之后五档的入口权重才真正分开（`causal_Link`：P0 17005、P1 29511、P2/P4 154418、P3 7）。

## 2. 语义不变性 Gate（文档 §3.2）：通过

| 检验 | 结果 |
|---|---|
| 小规模 3 实例 × 3 策略 | 最优值全部一致 |
| 调试集 36 个可证明实例 × 5 策略 | 0 例不一致 |
| 全量 384 个可证明实例 × 2 策略（种子 20260909） | 0 例不一致 |

分层策略只改变假设层的组织顺序，不改变目标语义——这条最重要的正确性前提成立。

## 3. H1：没有任何策略优于 P0 的证明数

调试集（50 实例，种子 20260909）：

| 策略 | 证明 | 平均墙钟 | 相对 P0 的末态 UB |
|---|---|---|---|
| **P0** | **36/50** | 217 s | — |
| P1 | 35/50 | 223 s | 4 好 / 2 差 |
| P2 | 34/50 | 223 s | 6 好 / 3 差 |
| P3 | 34/50 | 230 s | 5 好 / 6 差 |
| P4 | 33/50 | 221 s | 6 好 / 4 差 |
| S2 | 33~34/50 | 214 s | 6 好 / 6 差 |

全量 558 实例（P2 是最有理论依据的一档，单独验证）：

| 种子 | P0 证明 | P2 证明 | P2 末态 UB：更好 / 更差 |
|---|---|---|---|
| 20260909 | 379 | 374 | **82 / 40** |
| 20260910 | 378 | 371 | **81 / 44** |

**两种子一致的结论：P2 在 76 个实例上末态 UB 更好、34 个更差**（典型如
`MaxSATQueries...` 1394 → 318，`generalized-ising_IS13` 149.6e9 → 119.4e9，−20.2%），
代价是证明数稳定少 5~7 个。

按文档 §3.3 的口径：**H1（证明数或 anytime gap）在 UB 维度成立、在证明数维度不成立。**

## 4. H2：不成立（机制假设被证伪）

文档预期 P2 的增益集中在「UB 改善跨过硬化阈值」的实例上。实测（种子 20260909 全量）：

| 分组 | 实例数 | P0 运行中硬化过软子句的实例 |
|---|---|---|
| P2 UB 更好 | 82 | **0（0%）** |
| P2 UB 更差 | 40 | 0（0%） |
| 平 | 420 | 54（13%） |

即 P2 的收益恰恰全部发生在**完全没有发生硬化**的实例上；而真正发生硬化的实例大多是平局。
硬化阈值不是这条策略的收益来源。

## 5. H3：成立——在线控制器回收了 oracle 收益的 66%

调试集上，「事后按实例挑最好的策略」相对 P0 的累计相对收益是 58.50%，其中只有 7/50 个实例存在更优策略。
S2 在线控制器（零额外预算）实际拿到 38.60%，**回收比例 66%**，高于文档设定的 50% 门槛。

## 6. H4：收益按实例族高度集中

P2 的 UB 胜负按实例族（种子 20260909，净胜排序）：

| 实例族 | 更好 | 更差 |
|---|---|---|
| generalized-ising | +15 | 0 |
| decision | +13 | 0 |
| correlation-clustering | +10 | 2 |
| ramsey | +4 | 0 |
| railway-transport | +4 | 0 |
| judgment | +5 | 5 |
| hs-timetabling | +4 | 3 |

收益集中在少数权重结构特殊的族上，其余族基本无差别——这解释了为什么整体证明数只会略微下降。

## 7. 结论

- **S 线的正向效果成立**：P2（硬化对齐边界）在两种子下稳定改善 76 个实例的末态 UB，是本文第一条可复现的正面结果。
- **代价明确**：证明数少 5~7/558，因此 P2 适合作为「解质量优先」的配置，而不是「证明数优先」的配置。
- **机制解释需要修正**：收益不来自硬化阈值（H2 被证伪），而集中在少数权重结构的实例族上。
- **在线自适应可用**：S2 在零额外预算下收回 oracle 收益的 66%，说明「按可观测进展切换边界」是可行的调度形式。
## 8. S 线与 A 线的交界消融（`HybridLate` + P2）

批次 `runs/late_strat0` 与 `runs/late_strat2`（50 实例，HybridLate，30/10，种子 20260909）：

| 配置 | 证明 | 末态 UB（相对 P0 边界） |
|---|---|---|
| HybridLate + P0 边界 | **36/50** | — |
| HybridLate + P2 边界 | 34/50 | 1 好 / 4 差 |

**结论：P2 的上界收益无法迁移到混合场景。** 在纯 CASH 上 P2 用 76 好 / 34 差换来一份上界收益；
一旦换成混合（SPB 已经在上界上做功），P2 既没有额外的上界收益，还多丢 2 个证明。
这条消融把 S 线的适用边界钉死了：**P2 是「纯 CASH、解质量优先」的配置**，
不与混合协议叠加使用。

## 10. 语义不变性的分层核对（重要）

| 路径 | 可比实例 | 最优值不一致 |
|---|---|---|
| CDCL（exit_reason=optimum） | 362 | **0** |
| SCIP（exit_reason=optimum_scip） | 50 | **1** |

CDCL 路径完全一致，说明分层边界策略不改变语义——这正是文档 3.2 节要求的 Gate。

唯一的不一致出现在 SCIP 路径：ParametricRBACMaintenance_mse20_wt-role_smallcomp_multiple_0.0_2
在五个策略下分别报出 88608（P0/P2/P3）、90880（P1）、74976（P4）。同一实例、同一输入被 ILP 分量
判为最优却给出三个不同的值，说明 SCIP 通道存在与分层策略无关的一致性问题。证据：该实例每次运行都在
1.3~4.6 秒内以 optimum_scip 结束，根本没有走到分层决策；同配置连跑 5 次结果完全一致（88608），
说明不是随机噪声。这条需要单独定位（可能在 SCIP 异步结果读取或预处理对 weighted_instance 的改写上），
但不影响 S 线结论：策略控制的是 CDCL 路径，而该路径零不一致。
