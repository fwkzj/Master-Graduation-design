## 0. 前提：现在的分层启发式到底是哪一条规则

分层实现在 `CASHWMaxSAT-DisjCad-S6/code/uwrmaxsat/MsSolver.cc`（引用行号对应 HEAD = `3432a75`）。
**BMO/GBMO 的判定不属于本文范围**；本文关注的是判定之后真正决定「下一层切在哪里」的那段启发式。
它只有一条生效规则，其余入口都是二值选择：

| 位置 | 内容 | 状态 |
| --- | --- | --- |
| `:235-264` | `opt_stratification()`：按权重间隙挑最多 10 个切分点（`:249` 是函数头，`:264` 是 `}*/`） | **整段位于 `/* */` 注释内** |
| `:809` | 上述函数的唯一调用点 | **已注释** |
| `:278` | `bound = max(lower_bound, max_assump_Cs - max(weight_t(1), max_assump_Cs / 2))` | **生效**；主循环换层时唯一的边界规则 |
| `:816-819` | 用方差与均值的比较，在 `lower_bound` 取 `0` 或 `avg_soft_weight` 之间二选一 | 生效；初始入口的选择 |
| `:1161` | 主循环再次调用 `do_stratification`（`flag=false`，即启用 `:278` 的规则） | 生效 |

结论：**当前的分层边界规则是「以当前最大剩余权重为锚的几何对折」**——取本层最大权重 `W`，
在 `W − max(1, W/2)` 处切一刀，把权重 ≥ 该处的子句并成一层，只有遇到 `multi_level_opt` 标记的
BMO/GBMO 点才强制断开。它只读取两个量：`sorted_assump_Cs.last()` 与 `lower_bound`。

### 0.1 这条规则对三个决定性能的量都不敏感

一次分层边界同时决定三件事：

1. **假设集规模** `n(b)`：这次 SAT 调用要同时决定多少个软子句的松弛；
2. **权重质量** `M(b) = Σ_{w ≥ b} w · count`：这一层最多能换回多少下界推进；
3. **可硬化批次**：`harden_soft_cls()` 的判据是当前目标区间 `UB − LB`（`:318-321` 的 `Ibound` 与 `wbound`），
   权重严格大于该区间的软子句会在本层内立刻被硬化（`:321` 起）。

几何对折对这三者都不看，于是：

- 权重长尾时，`[W/2, W]` 内可能只有两三个大权值子句，一层换来的 LB 推进极小，调用次数却照常增加；
- 权重密集时，同一区间可能塞进上万个假设，单次 SAT 调用被拖慢；
- 与 `UB − LB` 无关，因此「这一层正好切在硬化阈值处」只能靠运气。

### 0.2 支撑事实（沿用 A 线 §0，不重复展开）

- `runs/full2cfg`：损失 100% 落在 CaDiCaL 桶，ILP 路径 37:37 无损失——分层与调度确实能改变证明能力，改得动。
- `runs/iter2_debug50`：13 个实例被 SPB 提前改善过 UB，最终只有 6 个保持领先——外部 UB 的价值尚未进入精确侧的搜索组织。

## S1. 分层边界策略族（Stratification-boundary policies）

### S1.1 动因

由 §0.1，切分点是一个有目标函数、有可观测反馈的决策，而现在被写死成一个常数比例 1/2。
把它显式化以后，至少有三个可验证的问题：不同切法在什么权重结构下更好；最优切法是否随实例变化；
以及切法与混合框架的 UB 通道如何咬合。

### S1.2 设计：把边界抽成策略接口

把 `:278` 抽成

```cpp
weight_t MsSolver::next_level_boundary(
        const vec<weight_t>& remaining,  // 剩余权重（升序、去重）
        weight_t lower_bound,            // delayed_assump 给出的下界地板
        Int LB, Int UB,                  // 当前内部目标区间
        const LevelStats& hist);         // 上一层的可观测结果
```

策略必须满足的不变量（一旦破坏就是改动了语义，而不是改进了搜索）：

1. 返回的 `b` 落在 `[lower_bound, remaining.last()]`；
2. 层集合随 `b` 单调：`b1 ≤ b2 ⇒ 层(b1) ⊆ 层(b2)`；
3. 不跨越 `multi_level_opt` 标记的 BMO/GBMO 点；
4. 所有权重恰好属于一层（覆盖且不重叠）。

### S1.3 候选策略

| 编号 | 策略 | 边界取法 | 动机 |
| --- | --- | --- | --- |
| P0 | 几何对折（现状） | `W − max(1, W/2)` | 基线 |
| P1 | 质量均衡 | 使 `Σ_{w ≥ b} w · count ≈ α · 剩余总质量` | 让每层的 LB 增益大体相当，而不是权重值相当；对长尾分布与 P0 差异最大 |
| P2 | 硬化对齐 | 取不超过 `UB − LB` 的最大权重；若 `UB − LB` 低于最小权重则退化为 P0 | 让假设层恰好等于「当前区间还可能硬化」的那批子句，直接贴合 `:318-321` 的判据 |
| P3 | 间隙驱动 | 在最大相对间隙处切，且要求间隙大于其下全部权重之和 | 修正并复活 `opt_stratification`，作为对照基线 |
| P4 | 代价模型 | 在 `n(b) ≤ N_max` 约束下最大化 `M(b)/n(b)` | 显式权衡假设集规模与质量收益 |

### S1.4 与混合框架的耦合点（本文的核心动机）

`P2` 显式使用 `UB − LB`，而 `UB` 可以来自 SPB 的交接。于是**局部搜索每交回一个更好的 UB，
CASH 下一次分层就自动换一种切法**——不需要额外增加「重规划触发器」，分层启发式本身就是 UB 的函数。

这把当前「SPB 只贡献一个数值」的交互，变成「SPB 改变精确侧的搜索组织」。消融也干净：
`HybridNatural` 与启用 P2 的版本都非抢占，只差边界规则这一处。

### S1.5 目标函数

若要走 P4，需要一个显式标量。三个量都能在切分时刻拿到：假设集规模 `n(b)`、
权重质量 `M(b)`、以及当前区间下可硬化的子句数。一个可用的形式是
「在 `n(b) ≤ N_max` 下最大化 `M(b)/n(b)`」；`N_max` 是单次 SAT 调用的规模预算，
可由上一层的实测耗时在线修正。

## S2. 在线自适应切分比例

把 `α`（P1）或 `N_max`（P4）当成实例相关的量，用每轮可观测的 `ΔLB / 本层 SAT 调用耗时`
做在线更新（爬山或小臂老虎机即可），不占用额外求解预算。要回答两个问题：

1. 最优切分比例是否确实随实例结构变化（权重分位数、不同权值个数、最大最小比、间隙熵）；
2. 在线控制器在零额外预算下，能收回事后最优（oracle）收益的多大比例。

## 3. 实验与验证

### 3.1 强制策略对照

新增 `-strat=` 开关，把 P0–P4 各跑一遍 MSE23W / MSE24W，得到逐实例事后最优（oracle），
再量在线控制器的后悔值。这张 oracle 曲线本身就是论文里可以放的结果，也是判断 S 线值不值得继续投入的依据。

### 3.2 语义不变性 Gate（最重要的测试）

不同切分策略下**最终最优值必须完全一致**：分层只改假设/松弛的组织顺序，不改目标。
测试成本很低（50 实例 × 4 策略比对最优值）。一旦某个实例不一致，说明策略改动越过了语义边界，
必须停下并回退。

**这条不变量目前只是机制推断，尚未在代码里验证。** `harden_goalval` 的累加（`:287`）与
`last_soft_added_to_sat` 的记账（`:305`）是否真的与切分顺序无关，需要先写这个回归测试确认；
若不成立，那是一条比性能更重要的发现，整个设计要重新收敛。

### 3.3 可证伪判据

- **H1**：存在实例子集，使某个非 P0 策略显著优于 P0（证明数或 anytime gap）。
- **H2**：P2 的增益集中在「UB 改善跨过硬化阈值」的实例上；未跨阈的实例上与 P0 无差别。
- **H3**：在线控制器在零额外预算下收回事后最优收益的显著比例（例如 ≥ 50%）。
- **H4**：结论按权重分布特征分层后仍成立（不同权值个数、最大最小比、间隙熵、有无 BMO 点）。

若 H1 不成立，则说明几何对折在这批基准上已经是够好的默认，S 线应降级为讨论章节。

### 3.4 机制可观测

`events.jsonl` 与求解器日志需补每层的 `boundary`、层内权重区间、假设集规模、层前后 LB、
本层硬化子句数。没有这些字段就只能报总体数字，无法解释胜负来源。
