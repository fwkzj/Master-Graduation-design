- `reports/templates/proposal/`：学校提供的开题材料模板。
- `reports/templates/midterm/`：学校提供的中期检查与报告模板。
- `literature/papers/`：MaxSAT 相关论文原文。
- `literature/reading-list/`：精读文献清单及其 PDF 版本。
- `project/`：不含凭据的环境配置示例和项目使用说明。
- `archive/legacy-planning/`：启用 `.planning/` 前留下的旧规划文件，只作历史参考。
- `archive/duplicate-files/`：与活动文档内容相同、仅文件名不同的保留副本。

活动研究计划只维护在仓库根目录的 `.planning/2026-09-09-thesis-hybrid-wpms/` 中。
